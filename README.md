# android_studio
cosas que hice en android
Una apk de una app que hicimos para un proyecto piloto de aysa.

# Permite cargar fotos y videos

Parsea videos y fotos en base 64 para optimizar espacio, almacena localmente con patrón de diseño DAO, y sincroniza regularmente una vez que chequeó la conexión a internet es correcta.
Así permite rellenar formularios y adjuntar fotos a los mismos.
